燕 / Tsubame Phase 8B-UI.1 - マルチモニター復元修正

前提:
  Phase 8B-UI（音声ミキサー別窓化）適用済み。

修正内容:
  1. 音声ミキサーの実行中「画面外救出」判定を削除。
     outer_rect はデスクトップ全体の座標、monitor_size は現在モニターのサイズなので、
     直接比較するとサブモニターへ移動した正常な座標を画面外と誤判定していました。
  2. 音声ミキサーはOSが報告した実座標/実サイズをそのまま保存。
  3. プレビューにも位置/サイズ保存を追加。
  4. 再起動時、プレビューと音声ミキサーの両方に保存済み座標/サイズを指定。
  5. 旧 settings.json は追加フィールドが無くても None で読み込めます。
  6. 存在しないモニター座標の補正はWindows/eframe側のウィンドウ生成処理に任せ、
     生成後にOSが実際に決めた座標を次回用として保存します。

置換ファイル:
  apps/tsubame/src/app.rs
  apps/tsubame/src/settings.rs

確認手順:
  cargo test -p tsubame-stream settings::tests
  cargo test --workspace
  cargo build --release -p tsubame-stream

実機確認:
  A. 音声ミキサーをサブモニターへドラッグできる
  B. プレビューをサブモニターへドラッグできる
  C. 終了→再起動で両方がサブモニター上の前回位置/サイズへ戻る
  D. 片方を閉じた状態も次回の開閉状態に反映される
  E. サブモニターを外して起動した場合、Windows側が利用可能画面へ補正し、
     その実座標が保存されることを確認する

注意:
  このパッチは音声処理そのものには触れていません。
