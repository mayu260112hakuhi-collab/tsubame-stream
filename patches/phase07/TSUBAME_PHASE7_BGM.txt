燕 / Tsubame - Phase 7 ローカルBGMライブラリ / 音声レイヤー

対象:
  apps/tsubame/src/app.rs
  apps/tsubame/src/bgm.rs   (新規)
  apps/tsubame/src/lib.rs
  apps/tsubame/Cargo.toml

追加内容:
- 実行ファイルと同じ場所に bgm/ を自動作成
- bgm/ 以下を再帰スキャン
- MP3 / WAV / OGG / FLAC を認識
- BGMライブラリから音源を「音声」レイヤーとして追加
- ファイル選択から直接BGM追加
- 再生 / 一時停止 / 再開 / 停止
- ループ再生
- 0〜100% 音量調整
- 複数のBGMレイヤーを保持可能
- レイヤー削除時はそのBGM再生も停止
- patches/phase07/ にパッチを整理

現在のPhase 7の音声経路:
- BGMは rodio から Windows の既定出力デバイスへ再生します。
- そのため、燕のPC音声(WASAPI loopback)をMixしている場合は、そのPC音声側にBGMが入ります。
- まだ「BGM」という独立ミキサーチャンネルへ直接注入する段階ではありません。
  専用BGMチャンネル / 個別WAV / 配信Mixへの直接接続は次段階で実装予定です。

テスト:
1. 4ファイルすべて差し替え / 追加
2. cargo build --release
3. 起動後、exe横に bgm/ が作られることを確認
4. bgm/ にMP3/WAV/OGG/FLACを入れる
5. BGMライブラリの「更新」で表示されることを確認
6. 「追加」でレイヤー一覧に「音声 <ファイル名>」が出る
7. 再生 / 一時停止 / 再開 / 停止を確認
8. ループONで曲末から繰り返すことを確認
9. 音量スライダーが再生中にも反映されることを確認
10. 削除時に再生も停止することを確認

注意:
- Cargo.toml に rodio = "0.20" を追加しています。初回ビルドは依存関係取得で少し時間がかかる場合があります。
- この環境には Cargo / rustfmt がないため、こちらではビルド確認していません。
