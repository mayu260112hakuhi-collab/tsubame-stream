燕 / Tsubame - Phase 4 複数画像レイヤー

対象:
  apps/tsubame/src/app.rs

変更内容:
- 追加画像を 1 枚固定の Option から複数保持できる Vec へ変更
- 「＋ 画像」で何枚でも画像レイヤーを追加可能
- 各画像レイヤーに固有 LayerId を維持
- レイヤー順序どおりにプレビュー / 配信映像へ合成
- レイヤー一覧から画像を選択し、個別に移動・リサイズ・表示切替・削除
- 複数画像それぞれのロック状態を維持
- 画像ごとにドラッグ用 egui ID を分離

確認項目:
1. cargo build --release
2. 画像を2～3枚追加できる
3. 各画像を個別に選択・移動・リサイズできる
4. ロックした画像だけ動かなくなる
5. 手前 / 奥へで複数画像の前後関係が変わる
6. 選択画像だけ削除でき、他画像は残る
7. ししゃもとの前後関係も引き続き動く

注意:
- この環境には Cargo / rustfmt がないため、こちらではビルド確認していません。
- SVG / image/ 自動素材ライブラリは次段階です。
