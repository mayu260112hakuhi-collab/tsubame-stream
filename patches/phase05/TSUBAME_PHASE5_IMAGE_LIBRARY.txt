燕 / Tsubame - Phase 5 image/ 素材ライブラリ

対象:
  apps/tsubame/src/app.rs

変更内容:
- 実行ファイルと同じ場所に image/ を自動作成
- image/background/
- image/overlay/
- image/wipe/
- image/thumbnail/
  も自動作成
- image/ 以下を再帰スキャンして画像素材を一覧表示
- 対応形式: PNG / JPG / JPEG / WEBP / BMP
- 起動時に自動スキャン
- 「更新」で実行中に追加した素材を再スキャン
- 「フォルダを開く」で Explorer から image/ を直接開く
- ライブラリ一覧の「追加」で、その画像を通常の画像レイヤーとして追加
- Phase 4 の複数画像・ロック・前後順・移動・リサイズはそのまま維持

テスト:
1. cargo build --release
2. 燕を起動して image/ と各サブフォルダが作られることを確認
3. image/background/ などに PNG/JPG/WEBP を入れる
4. 「更新」で一覧に出ることを確認
5. 「追加」でレイヤーになることを確認
6. 複数素材を追加し、移動・リサイズ・ロック・前後入替が動くことを確認
7. 「フォルダを開く」で Explorer が開くことを確認

補足:
- 起動時は自動認識します。
- 起動後に素材を追加した場合は「更新」を押す方式です。
- SVG対応は次段階です。
- この環境には Cargo / rustfmt がないため、こちらではビルド確認していません。
