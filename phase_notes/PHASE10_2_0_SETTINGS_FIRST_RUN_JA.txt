Phase 10.2.0 - 設定保存・初回起動基盤

目的:
- 配布後に毎回設定し直さなくてよい状態を作る。
- 初回起動時の最低限の案内を追加する。
- 秘密情報を不用意に平文保存しない。

実装:
- %APPDATA%/Tsubame/settings.json に主要設定を自動保存。
- 1秒間隔で差分がある場合だけ保存し、毎フレームI/Oを避ける。
- 保存対象:
  * 配信プリセット
  * エンコーダー優先設定
  * 録画中プレビューモード
  * YouTube/Twitch 選択
  * 配信サーバーURL
  * 映像ビットレート
  * 入力/出力音声デバイスID
  * プレビュー別窓の表示状態
  * 初回起動完了フラグ
- ストリームキーは settings.json に保存しない。
- 初回起動時に「燕へようこそ」案内を表示。
- 設定画面に自動保存状態とストリームキー非保存方針を表示。
- settings.rs にJSON round-tripテストを追加。

バージョン:
- tsubame 0.19.0

注意:
- この環境には cargo/rustfmt が無いため、ローカルではコンパイル未確認。
- Windows側で cargo fmt --all / cargo test --workspace / cargo build --release を実行して確認する。
