Phase 10.0.0 Fix4: 縦型ミキサーを共通チャンネルストリップ化

- PC音声 / マイク / アプリ音声 / Master を同じ draw_mixer_channel_strip() で描画。
- タイトル / dB / ソース名 / メーター / フェーダー / % / Mute / Mix / WAV / 削除欄の高さを共通化。
- 外枠の幅・高さを全チャンネルで共通化し、参照画像のようなミキサーストリップ配列を目指す。
- Master は Mute / Mix / WAV の位置を disabled 表示にして、他列と高さを揃える。
- アプリ音声も同じ部品を使うため、今後チャンネル追加時のズレを防止。
- 前回のような個別レイアウト調整による崩れを避けるため、列ごとの重複UIを撤廃。
