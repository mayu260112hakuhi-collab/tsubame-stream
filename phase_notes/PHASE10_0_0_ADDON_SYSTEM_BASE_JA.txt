Phase 10.0.0: 燕 Addon System 基盤

目的
- 配信・録画・キャプチャ・音声をコア機能として維持する。
- 追加機能はアドオン化し、本体更新で外部機能が壊れにくい境界を先に作る。

今回追加
- 左上トップバーに「設定」ボタンを追加。
- 設定画面を「通常設定 / 公式アドオン / 外部アドオン」の3画面に分離。
- Addon API v1 の定数とManifest/Registry基盤を追加。
- 公式アドオンの有効/無効スイッチUIを追加。
- Blender方式を想定した外部アドオン追加入口を追加。
- 外部アドオンはPhase 10.0.0では登録のみで、コード実行はしない。
- package/repository名 yaoyorozu-stream は互換性維持のため現時点では変更しない。
- 表示名は「燕 / Tsubame」へ移行開始。

安定性方針
- 本体内部実装と公開Addon APIを分離する。
- ADDON_API_VERSIONを互換性判定の基準にする。
- 外部ネイティブコードの直接ロードはまだ行わない。
- 将来のアドオン実行方式（別プロセス/WASM等）はAPI境界確定後に決定する。
